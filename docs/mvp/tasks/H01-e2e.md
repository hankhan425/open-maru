## Goal
Prove the core loop end to end in a production-like stack: donate → mandate → agent works through the gateway → verified spend and evidence appear publicly.

## Deliverables
- `compose.e2e.yaml`: Postgres, MinIO, server (`MIX_ENV=e2e`), web build, provider stub, Stripe CLI `listen` forwarding to the webhook endpoints (Stripe test mode keys from CI secrets).
- Login backdoor `GET /e2e/login?handle=`, compiled only for `MIX_ENV=e2e` and `dev` (a test asserts it 404s in `prod`).
- **Personas for manual testing (OQ-8).** Sign-in is passkey or GitHub/Google only, so testing as several people otherwise needs one browser profile and passkey (or provider account) each. The backdoor is in `dev` for this, plus:
  - `seeds_personas.exs` (idempotent; `seeds_e2e.exs` builds on it) creates Lumen Studio from `lumen.maru` (no track record is needed: pledges pay only for accepted work, and the test donations fit the $1,000 starting allowance, SPEC-05 §8.5), and:
    - @mina, the founder: creator, `core` holder, operator of `builder`.
    - @jo: `core` holder (accepted) with an expense mandate.
    - @sam: a member without a seat.
    - @lee: a signed-in user who isn't a member.
    - The `builder` agent.
  - Donors and public visitors need no account: sign out, and donate with Stripe test cards.
  - A dev-only persona switcher in the web app (`web/src/dev/`, behind `import.meta.env.DEV`) that signs in through the backdoor.
  - `mix openmaru.persona.token <handle>` prints a PAT for the CLI and MCP, and `mix openmaru.persona.token --agent builder` a mandate token for the agent persona (dev and e2e only).
  - `docs/ops/personas.md`: who each persona is and what to try as them, following PRD §5.
- Provider stub: Anthropic-format server with deterministic usage (streaming and non-streaming); price fixture for its model.
- `tools/byo-agent`: Node script using `@anthropic-ai/sdk` with `baseURL` = gateway and the minted token; plus `maru` CLI calls.
- Playwright specs below; CI job on main and nightly.
