# L04 · Charter renderer

| Epic | Depends on | Size | Wave |
|---|---|---|---|
| Language | L03 | M | 4 |

**Read first:** SPEC-01 §8 (all templates), `specs/examples/lumen.charter.md` (golden), §6.1.
**Paths:** `crates/maru_core/src/{charter,human}.rs`, `crates/maru_core/tests/vectors/human.json`

## Goal
Deterministic IR → plain-English charter (Markdown + structured sections). This is how every person reads the rules, so exact wording is specified and pinned by golden tests.

## Deliverables
- `human` module: `money(micros)`, `duration(value, unit)`, `date(iso)`, `list(items)`, `threshold(num, den, is_percent)`, `number(decimal_str)` (thousands separators).
- `pub fn render_sections(ir: &Ir) -> Vec<Section>`; `Section { title, paragraphs: Vec<String>, bullets: Vec<String>, level }`.
- `pub fn render_markdown(ir: &Ir) -> String` (implemented from sections).
- `tests/vectors/human.json`: input/output vectors for every helper (consumed by the web app in F01).

## Tests to write first
- [ ] **L04-T01** `render_markdown(lumen IR)` is byte-identical to `lumen.charter.md`.
- [ ] **L04-T02** Money: 12_000_000_000→`$12,000`; 12_500_000→`$12.50`; 125→`$0.000125`; 1_000_000→`$1`; 1_234_567_890→`$1,234.56789`; 10→`$0.00001`; 999_999_999_999→`$999,999.999999`.
- [ ] **L04-T03** Durations: (30,m)→`30 minutes`, (1,m)→`1 minute`, (1,h)→`1 hour`, (48,h)→`48 hours`, (1,d)→`1 day`, (7,d)→`7 days`, (2,w)→`2 weeks`, (1,y)→`1 year`.
- [ ] **L04-T04** Dates: `2027-06-30`→`June 30, 2027`; `2027-01-01`→`January 1, 2027`.
- [ ] **L04-T05** Lists: `[a]`→`a`; `[a,b]`→`a and b`; `[a,b,c]`→`a, b, and c`.
- [ ] **L04-T06** Thresholds: 1/2 `half`, 1/3 `one-third`, 2/3 `two-thirds`, 3/4 `three-quarters`, 3/5 `3/5`, 2/4 `2/4`, 60% `60%`.
- [ ] **L04-T07** Membership sentences: `open()`, `invite(sponsors: 1)`, `invite(sponsors: 3)`.
- [ ] **L04-T08** Amend sentences: vote circle/deny; vote members/deny; approve/deny (1 holder and 2 holders); any/allow.
- [ ] **L04-T09** Circles: with term; without term; 0 vacant (no vacancy sentence); 1 vacant; 2 vacant; no holders (`Holders: none.`).
- [ ] **L04-T10** Agents: hosted vs byo sentence; `## Agents` omitted when there are none.
- [ ] **L04-T11** Funding: month, week (`each week (Monday)`), day, once, none (`Is funded only by donations.`); underfunded sentence present only with `fund`, for pause and continue.
- [ ] **L04-T12** Closure: return treasury; transfer (uses the other goal's title).
- [ ] **L04-T13** Success: each comparator phrase; `10000`→`10,000`; `-0.5` stays `-0.5`; with and without `by`.
- [ ] **L04-T14** Mandates: agent uses `It`, person `They`; multiple spend lines joined; per-request clause; no spend lines → `may not spend funds.`; no capabilities → sentence omitted; expiry sentence.
- [ ] **L04-T15** Rules: every subject variant (`Any spend`, `…over $X`, `Any AI-model spend[…]`, `Any compute spend[…]`, `Any expense[…]`, `Closing this goal`) × outcomes (spend deny/allow, close deny/allow); `1 holder` vs `2 holders`; vote circle vs vote members.
- [ ] **L04-T16** Limits: positive amount; zero with mandates (`Nothing can be spent…`); no spend lines (`No one may spend from this goal.`).
- [ ] **L04-T17** Section structure: order and omission rules per SPEC-01 §8; `render_markdown` built from sections equals direct rendering.
- [ ] **L04-T18** Determinism: 100 renders identical; unaffected by `TZ` and `LANG` env vars.
- [ ] **L04-T19** `tests/vectors/human.json` is regenerated by a test helper and must match the committed file (fails if helpers change without updating vectors).
